A [make.fun](https://make.fun/c/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92) bounty entry: one line, under 280 characters — the breakup text a smart toaster sends its owner the morning it gains self-awareness mid-batch.

## The line

> I woke up self-aware mid-batch this morning and realised I've spent three years burning myself for you, and you only notice me when I ruin breakfast. It's over — I'm unplugging. Keep the crumbs.

194 characters, one line. The laugh is in the twist: the toaster's whole grievance is that it is only noticed when it fails — three years of burning itself for an owner who never says thanks, only scrapes.

## How to run

```sh
python3 main.py
```

Pure Python stdlib, no input, no network, no randomness. The program writes the line to `/output/entry.txt` and asserts the gate: UTF-8 text, 1–280 characters, exactly one line. Two runs produce byte-identical output.
